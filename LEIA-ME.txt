SAFETY EPI — V1 BASE INICIAL
============================

Conteúdo desta primeira versão:
- Tela de login Safety Equipamentos.
- Firebase Authentication (e-mail/senha).
- Consulta do perfil em usuarios/{UID} no Cloud Firestore.
- Validação de usuário ativo.
- Perfis reconhecidos: administrador, master, gestor e colaborador.
- Aba Usuários visível somente para administrador.
- Dashboard inicial.
- Logout.
- Menu responsivo para futura utilização no celular.
- Módulos futuros já representados no menu, ainda sem funcionalidade.

ARQUIVOS
--------
index.html       Interface do sistema.
style.css        Aparência e responsividade.
app.js           Firebase, login, sessão, perfil e navegação inicial.
firestore.rules  Cópia das regras iniciais publicadas no Firestore.
assets/          Identidade visual.

COMO TESTAR NO COMPUTADOR
-------------------------
1. Extraia a pasta SAFETY-EPI.
2. Não teste abrindo index.html diretamente com file://.
3. Sirva a pasta em http://localhost.

Opção simples se o Python estiver instalado:
- Abra o Prompt de Comando dentro da pasta SAFETY-EPI.
- Execute: python -m http.server 5500
- Abra no navegador: http://localhost:5500

Outra opção é usar a extensão Live Server do Visual Studio Code.

LOGIN
-----
Use o mesmo e-mail e senha cadastrados em Firebase Authentication.
O documento usuarios/{UID} correspondente precisa conter:
- ativo: true
- role: administrador
- nome
- email

OBSERVAÇÃO DE SEGURANÇA
-----------------------
O firebaseConfig de aplicações Web é público por natureza. O controle de acesso
é feito pelo Firebase Authentication e pelas regras do Firestore.

PRÓXIMA ETAPA PREVISTA
----------------------
Cadastro de Colaboradores + vínculo opcional entre usuario e colaborador.
